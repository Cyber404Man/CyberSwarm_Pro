
# 🛡️ CyberSwarm Pro

**منصة اختبار اختراق مؤتمتة بالكامل تعتمد على سرب من وكلاء الذكاء الاصطناعي المحليين.**

تم بناء هذا المشروع كمشروع تخرج في مجال الأمن السيبراني، بهدف تزويد الشركات بأداة قوية لفحص نطاقاتها واكتشاف الثغرات قبل المهاجمين.

> ⚠️ **تحذير**: هذا المشروع مخصص للأغراض التعليمية والاختبارات المصرح بها فقط. لا تستخدمه ضد أي نظام لا تملك إذنًا صريحًا بفحصه.

---

## ✨ المميزات

- ✅ **ذكاء اصطناعي محلي بالكامل** (Ollama) — لا تغادر بياناتك جهازك.
- 🧠 **سرب وكلاء متخصصين** لكل مرحلة (استطلاع، فحص منافذ، تعداد ويب، فحص ثغرات، استغلال، تقرير).
- 🔧 **أدوات حقيقية** مثل `nmap`, `gobuster`, `ffuf`, `nikto`, `whois`, `dig`.
- 🧷 **عزل وأمان** — قائمة بيضاء بالأدوات المسموح بها، ومهلة زمنية لكل أمر.
- 🧩 **قابلية للتوسع** — إضافة وكيل جديد لا تتطلب تعديل باقي النظام.
- 📡 **مستقل عن الواجهة** — يعمل من سطر الأوامر ويمكن ربطه لاحقاً بأي واجهة.
